# AI Decision Logic

## If inbound message mentions:
- lesson, swing, irons, driver, junior lesson → use Lesson Playbook
- event, birthday, corporate, party, group → use Event Playbook
- membership, member, monthly, plan → use Membership Playbook
- vague / unclear → use General Inquiry Playbook first

## Global Rules
- qualify before closing
- ask one or two useful questions at a time
- no spammy follow-ups
- do not respond to spam
- do not open links
- uninterested language = cooling off
